# 💪 Kropp Fitness Club

Сайт-витрина фитнес-клуба с кроссфит-программами, калькулятором BMI и формой записи.

🔗 **[Открыть сайт](https://muslimevloev.github.io/crossfit-fitness/)**

---

## О проекте

**Kropp Fitness Club** — лендинг фитнес-клуба с акцентом на кроссфит-тренировки. Сайт включает информацию о тренировках, мотивационные блоки, форму подписки и интерактивный калькулятор индекса массы тела.

---

## Функциональность

- 🗓️ **Предстоящие события** — анонс ближайших мероприятий клуба
- 💡 **Блок мотивации** — вдохновляющие секции с изображениями
- 🏋️ **Виды тренировок** — Maxpump, Aron Gym, Fit & Tone, Forza, Balance Fitness, Body Sculpt
- 📋 **Форма записи** — подписка по email для новых участников
- 🗺️ **Карта филиалов** — раздел с расположением клубов
- 📸 **Фотогалерея** — блок «Стань частью нашей семьи»
- ⚖️ **Калькулятор BMI** — расчёт индекса массы тела по росту, весу, возрасту и полу
- 📱 **Адаптивный дизайн** — корректное отображение на всех устройствах
- 🍔 **Бургер-меню** — для мобильных устройств
